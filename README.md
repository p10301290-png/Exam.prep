# PrepSpace — SSC CHSL Journal

Study planner PWA: syllabus, sessions, tests, mistake bank. Data is saved on your device (use Settings → Backup regularly).

## GitHub Pages par upload
1. GitHub par new repository banao (Public).
2. "Add file → Upload files" se is zip ke **andar ki saari files** (index.html, sw.js, manifest.webmanifest, icon.png, .nojekyll) drag karo. Zip ko as-it-is upload mat karo — pehle extract karo.
3. Commit karo. Phir Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder: / (root) → Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/REPO-NAME/

## Phone par install (Chrome)
1. Chrome mein wo link kholo.
2. Menu (⋮) → "Install app" ya "Add to Home screen" → Install.
3. App icon home screen par aa jayega aur full-screen khulega.

Update karne ke liye files replace karo aur sw.js mein `prepspace-v1` ko `prepspace-v2` kar do.
